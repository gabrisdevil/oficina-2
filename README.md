# Santana Auto mecânica — Site institucional + agendamento

Projeto simples (HTML, CSS, JS) com foco em:

- Home com proposta clara e CTA de agendamento.
- Página de serviços organizada por categorias mecânicas.
- Formulário de agendamento com nome, placa, serviço e descrição de sintomas.
- Contato rápido via WhatsApp e mapa.
- Estrutura planejada para área do cliente e painel admin.
- Script SQL para banco de dados de agendamentos.

## Como executar

Abra o arquivo `index.html` no navegador.

## Banco de dados

Use o arquivo `database.sql` em um PostgreSQL para criar as tabelas do sistema.
